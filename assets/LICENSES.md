# Asset licenses

Third-party assets bundled with the app. Every entry must allow commercial use.

## Original project artwork

The pixel-art sprites, icons, and backgrounds in `assets/pixel-src/export/` are generated
from original drawing routines in `scripts/generate-pixel-art.js`. They are not third-party
assets and require no external attribution. Run `npm run art` to regenerate the source PNGs
and their upscaled versions in `assets/`.
